# Python 面试题

Q: 什么是 Python 的 GIL？
A: GIL（Global Interpreter Lock）是 Python 解释器中的一个互斥锁，它确保同一时刻只有一个线程执行 Python 字节码。这意味着即使有多个 CPU 核心，Python 多线程也无法实现真正的并行计算。

Q: 列表和元组的区别是什么？
A: 列表是可变的（mutable），使用方括号 []，可以修改、添加、删除元素。元组是不可变的（immutable），使用圆括号 ()，创建后不能修改。元组通常用于存储不应该改变的数据。

Q: 什么是装饰器？
A: 装饰器是 Python 的一种高级功能，它允许你在不修改原函数代码的情况下，为函数添加新的功能。装饰器本质上是一个接收函数作为参数并返回新函数的函数。

# 数据库面试题

Q: 什么是数据库索引？
A: 数据库索引是一种数据结构，用于提高数据库表的查询速度。索引类似于书籍的目录，可以帮助数据库快速定位到所需的数据行，而不需要扫描整个表。

Q: SQL 和 NoSQL 的区别？
A: SQL 数据库是关系型数据库，使用结构化查询语言，具有固定的表结构和 ACID 特性。NoSQL 数据库是非关系型数据库，包括文档型、键值型、列族型和图数据库，通常更灵活，适合大规模分布式存储。
